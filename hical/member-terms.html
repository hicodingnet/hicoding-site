会员服务规则

生效日期：2026 年 9 月 23 日 · 广州海码智能科技有限公司

本规则适用于可期日历 HiCal（以下简称「本应用」）提供的会员服务（连续包月 / 连续包季 / 连续包年自动续期订阅）。本规则与《用户协议》《隐私政策》共同构成您与广州海码智能科技有限公司（以下简称「我们」）之间的约定。

会员服务属于增值服务，核心记录功能（月视图 / 重要日子 / 日程 / 提醒 / 时光记忆 / 云同步 / 小组件）对所有用户永远免费。

一、会员权益明细

  • AI 能力不限次数：AI 录入日程、AI 建议（准备建议 / 祝福语 / 今天的故事）共享每日不限次使用（免费版为每日 3 次共享额度，东八区自然日 0 点重置）。
  • AI 优享模型：会员请求优先使用能力更强的模型档位，生成更快、效果更好。
  • 时光云备份 10GB：重要日子的照片 / 录音 / 视频云端备份空间扩容至 10GB（免费版 500MB）。
  • 回忆报告与高清导出：年度回忆总结、年历相册无水印导出（陆续上线，上线后会员免费使用，不另行收费）。
  • 创始用户专属权益：创始窗口内首次登录的账号额外享有创始铭牌（永久有效、唯一编号）与创始礼（购买年付赠 3 张朋友会员券），详见下文第四条。

三、取消与退订

  • 取消方式：iOS——设置 → Apple 账户 → 订阅，选择可期日历取消；华为——设置 → 华为账号 → 付款与账单 → 自动续费 / 订阅，选择取消。取消即刻生效于当期结束后，当期内会员权益不受影响。
  • 到期回落：会员到期或取消后自动回落免费版（AI 每日 3 次、云备份 500MB）。您的日程、重要日子、时光记忆与云端数据完整保留、永不删除。
  • 退款：已扣费的当期服务费用一般不予退还（法律法规另有强制规定的情形除外），退款申请请通过对应应用市场渠道发起。

四、创始用户权益特别说明

  • 创始铭牌：创始窗口内（窗口时间以应用内公示为准）首次登录的账号获得创始铭牌，含唯一编号（#KQ-xxxx）与授予时间，永久有效，不随会员到期消失。
  • 创始礼（买年付送朋友券）：创始铭牌拥有者购买连续包年，即赠 3 张朋友会员券（每张可开通或顺延 1 个月会员），券自发放起 90 天内有效；朋友兑换后开通 / 顺延，每个账号限兑换 1 张朋友券，不可自兑。
  • 创始用户身份与权益不包含额外功能额度；新功能优先体验与共创通道为服务承诺，不构成收费对价。

五、规则变更与生效

  • 会员权益、价格或本规则如有调整，我们将通过应用内通知或本页更新提前公示；价格调整不溯及已生效的订阅周期（存量订阅按苹果 / 华为渠道的提前通知规则执行）。
  • 「永久」相关承诺仅限创始铭牌与创始用户身份本身，不延伸至未来新增的服务或功能。
  • 本规则未尽事宜，按《用户协议》《隐私政策》执行；两者不一致时，会员服务相关以本规则为准。
